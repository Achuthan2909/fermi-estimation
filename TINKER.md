# Tinker API Credits — Final Project

## Overview

[Tinker](https://thinkingmachines.ai/tinker/) is a distributed fine-tuning platform that supports LoRA-based SFT and RL on open-weights models.

- **Initial budget:** $50 per team
- **Maximum budget:** $100 per team (request more via [Ed Discussion](https://edstem.org/us/courses/94368/discussion) private post)
- **Docs:** [tinker-docs.thinkingmachines.ai](https://tinker-docs.thinkingmachines.ai/tinker/)
- **Cookbook:** [github.com/thinking-machines-lab/tinker-cookbook](https://github.com/thinking-machines-lab/tinker-cookbook)
- **Claude Code Skill:** Interact with the Tinker API directly from Claude Code — [github.com/sundial-org/skills/tree/main/skills/tinker](https://github.com/sundial-org/skills/tree/main/skills/tinker)

## Getting Started

0. **Coordinate:** Make sure you've coordinated with your team on who will be signing up / adding credits / generating the API key so that you don't duplicate efforts
1. **Sign up:** [auth.thinkingmachines.ai/sign-up](https://auth.thinkingmachines.ai/sign-up)
2. **Add credits:** Go to [thinkingmachines.ai/tinker/billing](https://thinkingmachines.ai/tinker/billing) → Payment methods → Enter the credit card number provided to your team
3. **Add $50 in credits** to your account
4. **Generate an API key** via the [API keys tab](https://tinker-console.thinkingmachines.ai/keys). Feel free to share these with your teammates.
5. **Start experimenting:** See the [Tinker Cookbook](https://github.com/thinking-machines-lab/tinker-cookbook) for SFT and RL workflow examples. Feel free to try some simple examples as you get your data/evals going.
